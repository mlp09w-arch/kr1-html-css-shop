# СветДом - магазин настольных ламп

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект представляет собой учебный интернет-магазин с каталогом из четырёх настольных ламп. Для проекта использованы фотографии ламп, предоставленные автором работы.

## Опубликованный сайт

GitHub Pages: https://mlp09w-arch.github.io/kr1-html-css-shop/

## Страницы проекта

- `index.html` - главная страница, преимущества и товары;
- `catalog.html` - каталог из четырёх ламп и статические фильтры;
- `product.html` - подробная страница лампы «Лайм»;
- `order.html` - единая форма заявки;
- `contacts.html` - адрес, телефон и время работы.

## Реализованные требования

- семантические теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация, якорные ссылки и хлебные крошки;
- карточки товаров;
- таблица характеристик;
- форма с HTML-валидацией;
- модальное окно на чистом CSS;
- внешний CSS-файл и переменные в `:root`;
- состояния `:hover`, `:focus-visible`, `:disabled`, `:user-invalid`;
- Flexbox и CSS Grid;
- классы по методологии БЭМ;
- позиционирование `relative`, `absolute`, `sticky`, `fixed` и `z-index`.

## Самостоятельные доработки

- собственное оформление магазина и цветовая схема;
- четыре разных товара с фотографиями, категориями, ценами и описаниями;
- бейджи «Новинка» и «Хит», состояния карточек при наведении;
- статические фильтры каталога и закрепление блока фильтров при прокрутке;
- подробная страница товара с характеристиками и другими вариантами;
- единая форма заявки с выбором товара, датой доставки и HTML-валидацией;
- модальное окно с условиями доставки, реализованное без JavaScript;
- хлебные крошки, внутренние ссылки и фиксированная кнопка «Наверх»;
- блок отзывов покупателей с оценками;
- улучшенная доступность: ссылка перехода к содержимому, подписи полей и видимый фокус;
- адаптация страниц для планшетов и телефонов.

## Используемые технологии

- HTML5;
- CSS3;

JavaScript и CSS-фреймворки не используются.

## Запуск

Можно открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Форма является учебной и не отправляет данные на сервер.
