# FORMA — дизайнерский свет для дома

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».

Тема: «HTML и CSS: разработка многостраничного сайта».

FORMA — многостраничный сайт интернет-магазина дизайнерских светильников. В проекте есть каталог со статическими фильтрами, подробная карточка товара, формы заявки и обратной связи, модальное окно и контакты шоурума.

## Опубликованный проект

GitHub Pages: https://mlp09w-arch.github.io/kr1-html-css-shop/

## Страницы

- `index.html` — главная страница с hero-блоком, преимуществами, популярными товарами, отзывами и FAQ;
- `catalog.html` — каталог из шести моделей, категории, фильтры и блок бесплатного подбора;
- `product.html` — карточка Aura Mini с описанием, ценой, отзывами и таблицей характеристик;
- `order.html` — подробная форма заявки на товар или подбор освещения;
- `contacts.html` — контакты, часы работы, схема проезда и форма обратной связи.

## Реализованные требования

- семантические элементы `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация, якорные ссылки и хлебные крошки;
- карточки товаров с БЭМ-классами и модификаторами;
- таблица с `caption`, `thead`, `tbody`, `th` и `td`;
- формы с `label`, `id`, `name`, нативной HTML-валидацией и понятными состояниями;
- модальное окно на основе `<dialog>`;
- CSS-переменные, `:hover`, `:focus-visible`, `:disabled` и `:user-invalid`;
- Flexbox для навигации и внутренних компонентов;
- CSS Grid для каталога, карточек и сложных блоков страниц;
- позиционирование `relative`, `absolute`, `sticky`, `fixed` и `z-index`;
- последовательное БЭМ-именование без inline-стилей и стилизации по `id`;
- локальные SVG-иллюстрации без внешних зависимостей.

## Самостоятельные доработки

Помимо базовой структуры методических указаний, в проекте разработаны:

- собственная визуальная концепция магазина и дизайн-система на CSS-переменных;
- расширенный каталог из шести товаров с бейджами и модификаторами карточек;
- статические фильтры по типу, цвету и цене;
- блок бесплатного светового плана;
- отзывы покупателей и раскрывающийся FAQ;
- выбор цвета в карточке товара;
- подробный сценарий заявки с пояснением следующих шагов;
- схема проезда до шоурума, выполненная средствами CSS;
- улучшенная доступность: skip-link, видимый фокус, подписи полей, `aria-live`, контрастные состояния;
- базовая адаптация интерфейса для небольших экранов и учёт `prefers-reduced-motion`.

## Локальный запуск

Проект не требует установки зависимостей или сборки. Откройте `index.html` в браузере либо запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

После запуска сайт будет доступен по адресу `http://localhost:8000/`.

Формы работают в демонстрационном режиме: проверяют введённые данные на стороне браузера и выводят сообщение об успешной отправке без передачи данных на сервер.
